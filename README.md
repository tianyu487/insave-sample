# InsAVE-80K sample — original clips

193 `*_original.mp4` source clips (5 s, 720p/24 fps, 16 kHz audio) extracted from the
evaluation split of [InsAVE-80K](https://huggingface.co/datasets/suimu/InsAVE-80K)
(Zheng et al., *InstructAV2AV*, arXiv 2605.18467). Hosted as release assets for direct-link access.

Direct link pattern: `https://github.com/tianyu487/insave-sample/releases/download/v1/<ID>_original.mp4`

Dataset annotations are MIT-licensed; the underlying media rights belong to their original sources.
